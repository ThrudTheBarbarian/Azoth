# AZCollectionView

The AZCollectionView class is a based on [BCCollectionView](https://github.com/sketch-hq/BCCollectionView) with a few changes to make it interact better. The AZCollectionView app highlights the use of the AZCollectionViewDelegate (which acts as source and delegate) to efficiently show every icon in the symbols font.
