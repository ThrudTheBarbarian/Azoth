# CollectionView sourcing

AZCollectionView isn't (quite) a clone of BCCollectionView, but it's very
heavily influenced by it, and even though BCCollectionView seems to be
abandonware, we're still complying with the license.

BCCollectionView is licensed under the BSD license - though it's not clear
which one since it doesn't include the actual license. The readme just 
states at the bottom
         "BCCollectionView is licensed under the BSD license"
 
 The source for BCCollectionView is available as an archived project at
 Github (https://github.com/sketch-hq/BCCollectionView) and hasn't changed
 in 14 years. 

It's not the worlds most comprehensive collection-view, and it doesn't 
adhere to the current AppKit CollectionView standards (being, you know, 
14 years old!) but it does do an excellent job of putting thousands of 
views into a scrollable list and remaining responsive, which tbh is all
I really need from a CollectionView. I can count the number of times 
I've wanted to (to pull an example out of the air) lay views out in a 
circle on the fingers of one hand, wearing a mitten, clenching my fist...
